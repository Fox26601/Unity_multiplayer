Mandatory · 40

  • Комнаты ≥3 игроков, capacity 2–10
  • ≥3 RPC разных типов + JSON MatchConfig
  • NetworkTransform на avatar / block / prop
  • Слоты персонажей — сервер владеет occupancy
  • Счёт / таймер / game over UI
  • Spawn / Despawn через NetworkRunner
Projectile без NetworkTransform: серверная networked pose, без double sync.

Reconnect

Crash ≠ Leave

  • Force-quit сохраняет token → кнопка Reconnect
  • Комната soft-lock: phase=Started, IsOpen=true
  • Неизвестный join после START — refuse
  • Известный token — reclaim avatar / slot / score
Если закрыть Photon-комнату, reconnect упрётся в GameClosed (32764) до нашего OnConnectRequest.

Dedicated

Серверный процесс

  • Запуск: … -batchmode -nographics -dedicated -room=Ded1
  • Клиенты Join → START (RPC) → сервер грузит карту
  • Сервер — единственный StateAuthority
  • Disconnect клиента → bot; Reconnect → контроль обратно

В редакторе для локальных тестов: Host create + Client join.

Демо · 5–8 мин

Сценарий показа

  1. 1. Boot → Create room (max ≥3)
  2. 2. Второй клиент Join → Lobby → START
  3. 3. Разные слоты → стрельба / chat / Tab
  4. 4. Force-quit → BOT → Reconnect
  5. 5. End / vote → Leave → Leaderboard

Вопросы

Короткие ответы

Почему NT не на Projectile?

Свой tick pose на сервере; NT давал конфликт интерполяции.

Почему комната не closed?

Нужен soft-lock для token reconnect без GameClosed.

Join vs Reconnect?

После START — только Reconnect с тем же token.

Custom NRB?

Свой Networking.NetworkRigidbody3D, без Fusion Physics addon.
