Reconnect

Crash ≠ Leave

  • Force-quit keeps the token → Reconnect button
  • Room soft-lock: phase=Started, IsOpen=true
  • Unknown join after START is refused
  • Known token reclaims avatar / slot / score
Closing the Photon room would hit GameClosed (32764) before our OnConnectRequest can accept the token.

Dedicated

Server process

  • Launch: … -batchmode -nographics -dedicated -room=Ded1
  • Clients Join → START (RPC) → server loads the map
  • Server is the sole StateAuthority
  • Client disconnect → bot; Reconnect restores control

Q&A

Short answers

Why no NT on Projectile?

Custom server tick pose; NetworkTransform fought interpolation.

Why not close the room?

Soft-lock keeps reconnect possible without GameClosed.

Join vs Reconnect?

After START, use Reconnect with the same token.

Custom NRB?

Our Networking.NetworkRigidbody3D, not the Fusion Physics addon.
